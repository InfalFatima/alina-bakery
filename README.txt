JOYFUL BAKES WEBSITE
====================

Files:
- index.html          Home
- story.html          Our Story
- mission-vision.html Mission & Vision
- products.html       Products
- unique.html         What makes us unique
- team.html           Our Team
- locations.html      Our Locations
- identity.html       Visual Identity
- community.html      Community & Sustainability
- contact.html        Let's Connect
- style.css           Shared design and responsive styles
- script.js           Active navigation, footer year, contact form demo

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Double-click index.html, or use the Live Server extension for a better development experience.
4. All pages link to one another through the navigation menu and page links.

TECHNOLOGY
HTML5, CSS3, Bootstrap 5.3.3 CDN, and vanilla JavaScript.

IMPORTANT
- Internet is required for the Bootstrap CDN unless Bootstrap is downloaded locally.
- The contact form is a front-end demo and opens the user's email app. Replace
  hello@joyfulbakes.example in script.js with the actual email address before publishing.
- Team names and locations are based on the provided PDF. Add real photos, contact details,
  prices, and exact location information when available.
